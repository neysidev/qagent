# QAgent — 5-minute demo script (production)

| Time | Screen | Voice-over |
|---|---|---|
| 0:00–0:30 | Landing page (fa) | "Small teams ship without QA. Customers find the bugs. QAgent tests your site like a real user." |
| 0:30–1:00 | Sign up | Create an account with email + password; land on the dashboard. "No setup, no code." |
| 1:00–2:30 | Dashboard → **Try on demo shop** | Live run: scenarios appear; the cursor moves, the action chip shows "Click: Remove"; read one agent thought aloud. Click a scenario to filter; scrub the timeline. Point at live time and cost. |
| 2:30–3:30 | Report | Summary cards; open the **High** bug: expected vs actual, repro steps, screenshot, `DELETE /api/cart/1 → 500` in network errors. Show the quantity bug (accepts 0/negative). Show an "agent stuck" verdict is labeled as not a site bug. |
| 3:30–4:00 | Share + export | Copy share link, open it in a private window (logged out). Download Markdown. |
| 4:00–4:30 | **Re-run** | Re-run the report: passed scenarios show "Replayed", run finishes in seconds, "Replayed — $0.00 LLM cost". |
| 4:30–5:00 | New test page | Show templates (signup, login, cart, contact) and the optional test account. Close with the benchmark numbers and pricing. |
